# Themes

Aplica un preset.

```lua
RevUI.SetTheme("midnight")
RevUI.SetTheme({ primary = Color3.fromRGB(255, 100, 100) })
```

Presets: `dark`, `midnight`, `sunset`, `forest`, `ocean`, `lavender`, `mono`, `candy`, `matrix`, `rose`, `arctic`, `emerald`, `coffee`, `synthwave`.

Claves: `primary`, `surface`, `surface2`, `text`, `textMuted`, `success`, `danger`, `warning`, `info`, `border`, `black`, `white`, `gray`, `purple`.

> También desde la ventana: `CreateWindow({ theme = "forest" })`.
